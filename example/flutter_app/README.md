# Flutter-приклад shevchenko

Готовий застосунок показує використання локального пакета `shevchenko` у
Flutter. Він має перемикач статі `М / Ж` і три незалежні текстові поля:

- **Звання** — наприклад, `солдат`;
- **ПІБ** — наприклад, `Тарас Григорович Шевченко`;
- **Посада** — наприклад, `помічник гранатометника`.

Після натискання **Тест** застосунок показує всі сім відмінків у порядку
`звання ПІБ посада`. Порожнє поле пропускається. Можна заповнити одне, два або
всі три поля; якщо всі порожні, застосунок просить ввести хоча б одне значення.
Обрана стать застосовується до звання, ПІБ і посади. Кнопка у блоці результатів
копіює всі сім рядків.

## Підтримувані формати ПІБ

Приклад розпізнає такі порядки компонентів:

- `Тарас Григорович Шевченко` — ім'я, по батькові, прізвище;
- `Шевченко Тарас Григорович` — прізвище, ім'я, по батькові;
- `Тарас Шевченко` — ім'я, прізвище;
- `Шевченко Тарас` — прізвище, ім'я;
- `Тарас Григорович` — ім'я, по батькові.

Для двох слів застосунок використовує закінчення по батькові, визначення роду
та поширені закінчення прізвищ. Якщо порядок неможливо визначити впевнено, він
показує помилку й пропонує додати по батькові. Рід визначається за ім'ям або по
батькові лише для розпізнавання порядку двох компонентів; для відмінювання
використовується вибір `М / Ж`. Бібліотечний API для готового рядка використовує явний
`FullNameFormat`; усі формати описані в [основному README](../../README.md#відмінки-поля-та-json).

## Вимоги

- Flutter SDK із Dart 3.11.0 або новішим у межах Dart 3.x;
- Chrome для запуску Web;
- Visual Studio з компонентом **Desktop development with C++** для Windows;
- Android SDK, емулятор або фізичний пристрій для Android.

Перевірте доступні платформи:

```sh
flutter doctor
flutter devices
```

## Отримання залежностей

З каталогу `example/flutter_app` виконайте:

```sh
flutter pub get --enforce-lockfile
```

Приклад імпортує бібліотеку через path-залежність `../..`. У власному
застосунку після публікації пакета виконайте `flutter pub add shevchenko` та
імпортуйте API так:

```dart
import 'package:shevchenko/shevchenko.dart' as s;
```

## Запуск

```sh
# Chrome
flutter run -d chrome

# Windows
flutter run -d windows

# Android: підставте ID з flutter devices
flutter run -d DEVICE_ID
```

## Аналіз, тести та release-збірки

```sh
dart format --output=none --set-exit-if-changed lib test
flutter analyze
flutter test
flutter build web --release
flutter build web --wasm --release
flutter build windows --release
flutter build apk --release
```

Запускайте тільки збірки для встановлених toolchain. Код форми розташований у
[`lib/main.dart`](lib/main.dart), а розбір і відмінювання введених значень — у
[`lib/declension_demo.dart`](lib/declension_demo.dart). Widget-тести перевіряють
перемикач статі, три поля, всі сім готових рядків, жіночий результат, порожні
значення та кожен підтримуваний формат ПІБ.
