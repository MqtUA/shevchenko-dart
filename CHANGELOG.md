# Changelog

## 0.9.0

- Support Dart 3.11.0 and newer; minimum SDK covered separately in CI.
- Initial pure Dart port of pinned shevchenko.js 3.2.2 and military extension.
- Five combined fields, seven cases, gender detection, typed and raw APIs.
- Original rules, overrides and fixed Float32 surname inference embedded offline.
- Instance-local extensions, custom WordInflector rules and immutable DTOs.
- Frozen parity fixtures and reproducible Dart-only data generation.
- Detailed CLI, Flutter and standalone Web integration examples.
- Flutter example with separate rank, full-name and appointment fields, an
  explicit male/female selector and combined output for all seven cases.
- Explicit full-name formats, including surname-first two-part names, and ordered
  batch declension for full-name strings.
- Development dependencies updated to current stable test, lints and crypto releases.
